# Moire

Образец сайта интернет-магазина, реализованный на Vue.js(2).
На сайте работает каталог с пагинацией и фильтрацией товаров, управление корзиной, 
формирование заказа (с расчётом итоговой суммы), валидация формы. 

Работа с Товарами и заказами использует REST API и  менеджер состояний вью (vuex).

Посмотреть можно здесь:
https://sm1lent.github.io/Moire/
